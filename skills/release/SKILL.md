# Release

## Checklist

1. Review the diff and remove unrelated changes.
2. Confirm documentation and configuration are aligned.
3. Confirm verification evidence is reproducible.
4. Check secrets, generated files, and local-only artifacts.
5. Prepare a concise commit message.
6. Summarize behavior, validation, risks, and follow-up work.

Never claim a remote push or release succeeded without checking the remote result.
